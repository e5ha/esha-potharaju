A.2: Recover Homographies

A homography is a 3 × 3 projective transform with eight independent parameters (the last entry is fixed to 1). For each matched point pair (x, y) → (x′, y′), I add two rows to A and the corresponding coordinates to b. Ten matches in Set 1 and seven in Set 2 give more equations than unknowns, so least squares finds the best-fitting transform rather than relying on only four points.

rows.append([x, y, 1, 0, 0, 0, -xp * x, -xp * y])
values.append(xp)
rows.append([0, 0, 0, x, y, 1, -yp * x, -yp * y])
values.append(yp)

A = np.asarray(rows, dtype=float)
b = np.asarray(values, dtype=float)
h, _, rank, _ = np.linalg.lstsq(A, b, rcond=None)
H = np.append(h, 1.0).reshape(3, 3)

The notebook also checks that the correspondences constrain all eight parameters; a rank-deficient system indicates degenerate matches, such as points that do not provide enough geometric spread.

A.3: Warp the Images

The output canvas is bounded by transforming the four source-image corners. I use inverse warping: for each output pixel, apply the inverse homography to find where to sample in the source image. This avoids holes that can happen when scattering source pixels into the output. A validity mask marks coordinates that land inside the source bounds.

inverse = np.linalg.inv(homography)
source = inverse @ destination
denominator = source[2]
finite = np.isfinite(source).all(axis=0) & (np.abs(denominator) > 1e-12)
source_x = np.zeros_like(denominator)
source_y = np.zeros_like(denominator)
source_x[finite] = source[0, finite] / denominator[finite]
source_y[finite] = source[1, finite] / denominator[finite]
inside = (
    finite
    & (source_x >= 0) & (source_x <= width - 1)
    & (source_y >= 0) & (source_y <= height - 1)
)

Nearest-neighbor interpolation rounds to the closest source pixel. Bilinear interpolation takes a weighted average of the four surrounding pixels; the fractional coordinate within that pixel neighborhood determines the weights:

top = (1 - dx) * flat_image[y0, x0] + dx * flat_image[y0, x1]
bottom = (1 - dx) * flat_image[y1, x0] + dx * flat_image[y1, x1]
sample = (1 - dy) * top + dy * bottom

Nearest-neighbor sampling is faster, while bilinear sampling produces smoother results under perspective transforms.

A.4: Blend the Images into a Mosaic

I use the center view as the common reference, transform each side view into that coordinate system, and compute a canvas large enough to contain all transformed image corners. For each valid warped pixel, its feather weight is the distance to the nearest source-image edge. Pixels near an edge contribute less; pixels nearer the center contribute more.

edge_distance = np.minimum.reduce(
    [source_x + 1, source_y + 1, width - source_x, height - source_y]
)
weights = np.maximum(edge_distance, 0).reshape(valid.shape)
weights *= valid
accum[y_start:y_end, x_start:x_end] += warped.astype(float) * weights[..., None]
total_weight[y_start:y_end, x_start:x_end] += weights

valid_mosaic = total_weight > 0
mosaic = np.zeros_like(accum, dtype=np.uint8)
mosaic[valid_mosaic] = np.clip(
    np.rint(accum[valid_mosaic] / total_weight[valid_mosaic, None]), 0, 255
).astype(np.uint8)

After accumulating the weighted colors, I divide by the total weight at each covered pixel. This feathered weighted average softens transitions between overlapping views instead of allowing one image to overwrite another. The notebook creates two-image mosaics first, then combines the center with both side images for each full panorama.
