CS180: Intro to Computer Vision and Computational Photography

Project 4A: Image Mosaics

Recovering projective transformations from image correspondences, warping overlapping views, and blending them into panoramas.

A.1: Shoot the Pictures

I captured two overlapping image sets: one inside Moffitt Library and one outdoors at CDSS. Each set contains left, center, and right views that are stitched into a wider panorama.

CDSS Outdoors

A.2: Recover Homographies

I marked corresponding points in overlapping Moffitt views and solved the resulting overdetermined linear systems with least squares. The recovered homographies map the first image in each pair into the second image's coordinate frame.

A.3: Warp the Images

The images are inverse-warped into the reference view so output pixels sample the source image without leaving gaps. The notebook compares nearest-neighbor sampling, which is quick but can look jagged, with bilinear sampling, which interpolates four nearby pixels for smoother results.

The notebook's rectification section still asks for four source corners and an image path, so no rectified-image result is included here.

A.4: Blend the Images into a Mosaic

I warp adjacent views into a shared canvas and combine overlapping pixels with feathered, edge-weighted averaging. This reduces the hard seams that would result from letting one image simply overwrite another.
